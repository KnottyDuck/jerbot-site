# Jerbot site

Static Direction A (“Product Terminal”) site for future Netlify deployment.

## Open locally

Open `index.html` in a browser. No build step, server, third-party dependency, analytics, or tracking is included.

## Pages

- `index.html` — landing, product portfolio, services offer, and dual-intent contact.
- `services.html` — concise software-services page; no invented pricing, team, client, or delivery claims.
- Product pages — Rug Pulled!, Rug Pulled! Live, and PubMint status/detail pages.

## Metadata and assets

Canonical and Open Graph/Twitter text metadata uses `https://jerbot.dev`. No OG image tag is included because no approved share image exists.

`assets/jerbot-character.svg` and `assets/jerbot-desk-mark.svg` are copied from the approved `jerbot-site-assets` export and used as restrained site motifs.
