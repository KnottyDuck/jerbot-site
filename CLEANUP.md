# Cleanup allowlist

This is a **regeneration allowlist**, not an instruction to delete anything. Paths are relative to the repository root. It authorizes no automatic deletion, blanket cleanup of ignored files, or worktree removal. Follow SOP-FILE-SYSTEM-AND-TASKS rule 19 before considering deletion.

| Exact path | Why it can be regenerated | Verified regeneration command |
| --- | --- | --- |
| `_site/` | Publish staging copy produced by the `Stage publish directory` step in `.github/workflows/deploy.yml`. Only an unmodified copy reproducible from the retained checkout qualifies. | The staging-only command below, copied from that workflow. |

From the repository root, with `rsync` available and `_site/` absent, the workflow creates the staging copy with:

```sh
mkdir _site
rsync -a ./ _site/ \
  --exclude '.git' \
  --exclude '.github' \
  --exclude '.netlify' \
  --exclude '.claude' \
  --exclude '_site' \
  --exclude 'README.md' \
  --exclude '.DS_Store'
```

This documents regeneration only; do not run the workflow's deployment step for cleanup. `_site/` is generated by the named command but is **not ignored** by the current `.gitignore`, and need not exist in a fresh checkout. The staging command copies local files as well as tracked source: do not assume everything inside it is disposable or safe to publish.

**Mandatory pre-delete check:** Match the exact path, confirm the workflow still produces it, run `git status --ignored --untracked-files=all -- _site/`, and inspect all contents, including nested files and symlinks. Confirm every staged file can be reproduced from retained source, with no unique edits, local-only material, secrets, or evidence needed by a handoff/review. Tracked files are protected. If any content is unexplained, changed, or not reproducible, stop and ask its owner. Git status or an ignore rule alone is insufficient; this document grants no deletion permission by itself.

## Not allowlisted / protected

- `.env*`, secrets, credentials, `*.local`, `.claude/`, and all local-only paths or content, including `.netlify/` CLI state and `.DS_Store`. The latter two are the only entries in the current `.gitignore`; neither has a verified regeneration recipe here.
- All source, documentation, configuration, tests, user-authored assets/data, and approved deliverables, including `assets/`, root icons, and `questionnaire.*`. `scripts/render-hero-cast.mjs` writes approved tracked artwork using an external pinned engine; that does not make the artwork disposable.
- Proofs, reports, captures, handoff evidence and inbox material, including `CollAgents-inbox/`, any `proofs/`, `test-results/` or `playwright-report/`, and any custom browser-test evidence directory. The browser scripts default to `/tmp/site-jerry-3-evidence` and `/tmp/jerbot-wishlist-evidence`; those external paths remain protected even though the tests can run again.
- `node_modules/`, `dist/`, and any other path not in the table. This static repository has no `package.json` or package lockfile, no dependency-install command, and no application build step (`README.md`). Do not invent an `npm ci` or build-based cleanup exception.

No files were deleted or regenerated to prepare this allowlist. No cleanup, deployment, or publication is authorized by this document.
