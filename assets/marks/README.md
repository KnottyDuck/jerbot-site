`stresslab.svg`, `avoiding-jayms.svg`, and `rug-pulled-live.svg` are transparent
pending files so the site makes no missing-image requests. A can replace each
file at the same path with approved SVG art. The home card loader shows the
mark only after the replacement decodes; a file with `data-pending-mark="true"`
stays hidden. Existing Rug Pulled! and PubMint marks use their current paths.
